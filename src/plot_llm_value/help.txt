NAME
  plot-llm-value - Compare language model capability against measured task cost.

DESCRIPTION
  Fetches fresh official Artificial Analysis data on every invocation, follows
  all pages, and compares model releases and reasoning settings. Use to choose
  models, inspect cost/capability tradeoffs, or display a comparison in chat.
  Cost is AA's measured USD per Intelligence Index task, never token pricing.
  Coding and Agentic plots still use Intelligence Index task costs on the x-axis.
  --x swaps cost for one of AA's median response times, measured on AA's own
  speed-benchmark prompts rather than Intelligence Index tasks.

INSTRUCTIONS
  1. Set ARTIFICIAL_ANALYSIS_API_KEY (or AA_API_KEY). Obtain a key at
     https://artificialanalysis.ai/data-api . No key is needed for help.
  2. Run models to discover exact family names, variant names, IDs and slugs.
  3. Run plot (the default) with providers, model families, or exact variants.
     Read the JSON result, open image_path with the host's image tool, and
     respond with ONLY the produced image unless the user requests analysis.
     A CLI cannot force the host to display images; the agent performs this step.
  4. Use data for LLM-readable JSON without rendering an image. Inspect excluded
     rows before drawing conclusions. Lower cost and higher score are better;
     these benchmark results do not predict every user's workload.
  5. On failure read stderr; correct selectors or credentials. For HTTP 429,
     wait the reported Retry-After interval. No stale data or web-scrape fallback.

SYNOPSIS
  plot-llm-value [plot] [SELECTION] [--series LABEL VARIANT VARIANT ...]
                 [--metric METRIC] [--x AXIS] [--reasoning-only] [--linear-x]
                 [--no-pareto] [--no-capability-lines] [--output PATH]
  plot-llm-value data [SELECTION] [--series ...] [--metric METRIC] [--x AXIS]
                      [--reasoning-only]
  plot-llm-value models [SELECTION] [--series ...] [--reasoning-only]
  plot-llm-value help | --help | -h

COMMANDS
  plot (default)
      Fetch all pages and render a PNG. Stdout: JSON with absolute image_path,
      plotted/excluded counts, capability_only, inferred_cost and pareto_frontier
      rows, and source metadata.
      Creates a unique temporary directory by default; files persist until OS
      cleanup. --output saves to an explicit .png, .svg or .pdf path (overwrites
      that file). All available settings of each release are connected in effort
      order; dashed segments indicate gaps. Model colors and provider marker
      shapes appear in the legend. Model and effort labels avoid points and lines.
      A dashed grey Pareto frontier is drawn by default through the plotted points
      that no other plotted point beats on both axes; --no-pareto omits it.
      A row with a score but no plottable cost (cost unavailable, or zero cost on
      a log axis) becomes a thin horizontal line at its score, labelled with the
      reason, and is listed in capability_only. Past 12 such rows the lines would
      hide the priced points, so none are drawn, the footer says so, and the JSON
      still lists every row (capability_lines_drawn reports which happened).
      --no-capability-lines omits them regardless. An unpriced effort whose rank falls
      inside a dashed effort gap of its own family instead becomes a hollow point
      on that segment: its score is measured, its cost interpolated by effort rank
      between the two measured neighbours, reported in inferred_cost with its
      effort label suffixed '?'. With --x, read 'cost' above as the chosen time:
      the reason reads 'time unavailable' and the guess is reported as
      inferred_<row field>, e.g. inferred_e2e_seconds. Neither kind joins the frontier, which needs
      measured costs; a measured zero cost is never treated as a guess.
      Only a missing score removes a row; those are excluded and reported.
      Fails if no row has a measured cost, since the x-axis would be empty.
  data
      Same live selection as plot; stdout: JSON with metadata, normalized rows,
      all three indices, cost, selected score, exclusion reasons and Pareto
      membership among comparable rows. No files. Zero cost is retained.
  models
      Fetch the live catalog; stdout: JSON with family, effort, provider, exact
      name, slug and ID for each row. Includes rows with missing measurements.
      No files. Selection flags may narrow the catalog.
  help, --help, -h
      Print this guide verbatim; no network or file writes. Exit 0.

OPTIONS
  SELECTION: choose ONE mode; omit to select all models. Values within a mode
  are unioned. Repeat the flag or supply several quoted values after one flag.
  --provider NAME [NAME ...]  Creator name, slug or ID (e.g. anthropic openai).
                             Provider means model creator, not inference host.
  --model FAMILY [FAMILY ...] Exact release family; includes ALL its efforts.
  --variant NAME [NAME ...]   Exact AA row name, slug or ID; only those settings.
                             Names are case-insensitive; no substring matching.
                             Unknown/ambiguous selections fail, never guess.
  --series LABEL VARIANT VARIANT [...]
                             Join two or more variants of one creator, even of
                             different releases, into one series named LABEL,
                             connected in the order given. Variants resolve as
                             --variant does and are added to the selection; alone,
                             --series selects only its variants. Each point is
                             labelled with its name minus the prefix the series
                             shares ('GLM-5.2 (max)' -> '5.2 (max)'); in JSON the
                             row's family is LABEL, effort that point label, and
                             series_rank its position. Repeat for several series.
  --metric METRIC            intelligence (default), coding, agentic (or agent).
  --x AXIS                   Plot and data: x-axis, lower is better. cost (default,
                             USD per Intelligence Index task); e2e (median
                             end-to-end response time, s); first-token (median
                             time to first token, s); first-answer-token (the
                             same, excluding reasoning tokens, s). Every row
                             carries e2e_seconds, first_token_seconds and
                             first_answer_token_seconds; compared rows add x, the
                             chosen value, and the result an x_axis block. A row
                             missing the chosen value is excluded from the
                             frontier as 'missing time', like 'missing cost'.
  --reasoning-only           Drop variants AA marks Non-reasoning (or 'none').
                             Applies to every command and changes the frontier,
                             which is always relative to the rows kept. A row
                             with no effort qualifier is a single-configuration
                             model, not a non-reasoning variant, so it is kept.
                             Most such variants have a score but no measured
                             cost, so they can only be capability lines here.
  --linear-x                 Linear cost axis; default is logarithmic.
  --no-pareto                Plot only; omit the Pareto frontier line, which is
                             drawn by default. JSON Pareto fields are unaffected.
  --no-capability-lines      Plot only; never draw horizontal capability lines
                             for scored rows without a plottable cost. They stay
                             in capability_only. Hollow gap points are unaffected.
  --output PATH              Plot only; .png, .svg or .pdf. Parent must exist.
  --timeout SECONDS          Positive per-request timeout (default 30).
  --env-file PATH            Read API key from this dotenv file explicitly.
                             Process environment takes precedence. No automatic
                             search for config or .env files; no shell evaluation.
  --help, -h                 Show this complete guide from any command.

EXIT STATUS
  0  Success.
  1  API/network, invalid response, missing key, or output-file error.
  2  Usage, unknown/ambiguous selection, or no comparable measurements.
  Errors go to stderr; stdout contains only a complete success result.

ENVIRONMENT
  ARTIFICIAL_ANALYSIS_API_KEY  API key; takes precedence over AA_API_KEY.
  AA_API_KEY                 Alternative key name.
  TMPDIR, TEMP, TMP          Python's standard temporary-directory locations.
  MPLCONFIGDIR              Optional Matplotlib config/cache directory.

EXAMPLES
  # After setting the API key in your environment:
  plot-llm-value models --provider anthropic openai
  plot-llm-value --provider anthropic openai
  plot-llm-value plot --model 'gpt-oss-20B' --metric coding
  plot-llm-value data --variant 'gpt-oss-20B (high)'
  plot-llm-value --provider anthropic --metric agentic --linear-x --output compare.svg
  plot-llm-value --provider google --no-pareto
  plot-llm-value --provider anthropic openai --reasoning-only
  plot-llm-value --env-file .env --provider openai
  plot-llm-value --provider anthropic --x e2e --output e2e.png
  plot-llm-value --model 'Claude Opus 5.5' --series z.ai 'GLM-5.2 (max)' 'GLM-5.3 (max)'

OUTPUT
  Plot: {"image_path":"/tmp/plot-llm-value-.../comparison.png", ...}
  Agent: display that image inline, with no extra prose by default.
  Data: {"schema_version":1,"source":{...},"metric":{...},"rows":[...], ...}
  Source includes endpoint, retrieval time and AA Intelligence Index version.
  Every result echoes the applied filters, so a frontier can be reproduced.
  Null means unavailable, never zero. Exclusions are explicit. Pareto optimal
  means no selected comparable row is both no costlier and at least as capable,
  with one strict improvement. Exact ties remain on the frontier together.
  The drawn line and pareto_frontier use only the plotted rows, so they can
  differ from data's pareto_optimal whenever a row is excluded from the plot.
